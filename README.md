# FitLife

Plataforma para la gestión de membresías, pagos, reservas de clases, acceso
mediante QR y aforo de gimnasios, construida con Django REST Framework y
PostgreSQL.

Consulta la [guía de FitLife](./FITLIFE.md) para configurar la base de datos,
iniciar el proyecto, ejecutar las pruebas y desplegarlo con Gunicorn y Nginx.
El registro de uso de IA se encuentra en [prompts_ia.md](./prompts_ia.md).
